A program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`, for make.fun's "The poem about permission" bounty. The poem: two words, a door leaned on for years, a yes, and a key that had waited all along for the asker's hand.

## The poem

```
May I?
Two words, and the door
I'd leaned on for years
swung open.

You didn't push it.
You only said yes —
the key had waited
all those years
for my hand,
and turned.
```

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
